FAQ

Common questions for the NepaHub flow.

Does payment verify automatically?

Not in this static build. The student submits proof and the owner can mark it verified. Automatic verification needs the payment provider's merchant API/webhook.

Can the owner dashboard be completely private?

Yes with server-side authentication. In this static demo it is only UI-gated, so it should not be treated as a security boundary.

Can I use GitHub Pages?

Yes for the front end. For real accounts, orders and payment webhooks, connect it to a backend service and database.
